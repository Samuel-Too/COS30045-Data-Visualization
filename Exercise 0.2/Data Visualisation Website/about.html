About This Project

This demonstration website was developed for Swinburne University's web data visualization unit. It lays the foundational web design structure for future interactive data visualisations powered by D3.js.

The goal is to provide accessible energy consumption data to help Australian households reduce their environmental footprint and electricity expenses.
